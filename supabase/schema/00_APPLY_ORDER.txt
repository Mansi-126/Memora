App tables: public.folders, public.sources (all other data is Supabase Auth-managed).

Dashboard vs database (no separate tables):
  • Collections  = rows in public.folders; contents = sources with that folder_id
  • Artifacts    = rows in public.sources where source_type = 'artifact'
  • Favorites    = rows in public.sources where is_favorite = true
  • Sources      = public.sources (API may filter by folder_id, source_type, is_favorite)
